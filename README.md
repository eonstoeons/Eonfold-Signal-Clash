# EONFOLD: Signal Clash

A fast 2D science-fiction fighting game featuring six robot competitors, five arenas and four single-player modes.

## Play

Open the HTML file in a modern browser. No installation or internet connection is required.

## Controls

Arrow Keys — Move, jump and crouch
A / S — Hand techniques
D / F — Leg techniques
Hold Away — Guard
Esc or P — Pause

Touchscreen controls are included for mobile devices.

## Features

* Signal Match
* Endless Signal
* Signal Ladder
* Calibration Lab
* Easy, Medium and Hard difficulty
* Offline single-file design
* Built-in accessibility settings
