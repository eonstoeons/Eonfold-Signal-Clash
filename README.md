# v01d-beatdown
A complete 2D fighting game in one self-contained HTML file. Six fighters, five stages, an endless survival mode and full touch support — with zero image files, zero audio files and zero network requests. Every sprite, stage, sound and music track is generated in code at boot. Built With Claude AI.
Feel free to mod with or without AI and release your own version as a mod.
